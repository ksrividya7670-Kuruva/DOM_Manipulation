## JavaScript DOM and Event Handling
# Project Overview

This project demonstrates the use of JavaScript DOM manipulation and event handling. Users can enter their name in an input field and display a greeting message. The project also includes interactive boxes whose background colors can be changed using click events.

## Features
Display a personalized greeting message.
Access and manipulate DOM elements using JavaScript.
Handle button click events.
Change box colors dynamically.
Practice working with event listeners and DOM properties.


## Technologies Used
HTML5
CSS3
JavaScript (ES6)
Project Structure
index.html – Contains the webpage structure.
style.css – Contains styling for the page and boxes.
script.js – Contains JavaScript logic for DOM manipulation and event handling.


## How It Works

Enter a name in the input field.
Click the Greet button.
The heading updates with a personalized greeting.
Click on a box to trigger color-changing functionality.
Learning Outcomes
Understanding the Document Object Model (DOM).
Selecting elements using getElementById().
Updating content using innerHTML.
Handling user events such as clicks.
Modifying CSS properties dynamically with JavaScript.
